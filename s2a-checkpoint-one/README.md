My project idea is a 'pet caretaker' web application.
The user will be greeted with an on-screen 'pet' (appearance/species yet to be decided), which can be interacted with in various ways.
Examples of these interactions include: feeding, washing, customising and playing with the creature.
This will be done through a series of interactive draggable items such as brushes and food.
Creature memories and preferences will persist across sessions, and various creature needs will increase/reduce depending on player activity.

Art and visuals will be done via various CSS objects (e.g. one object for body, one for each hand etc.) to eliminate the need for time-consuming hand-drawn animation.
In addition, I am going to further research the 'GSAP' library to deduce what movement would be possible within the realm of those animations.
The backend API will store and serve the creature's memories, preferences and other statistics such as hunger.

I am loosely (very very very very loosely) toying with the idea of using RAG for creature speech - though this may not be realistic given the timeframe.
